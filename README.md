# Lapel: workwear rental (design exploration)

This is a subscription app for renting work clothes, built for new grads putting together their first work wardrobe. The repo is at the design stage, so there is no app code yet.

- Mockups: `.codeyam/design/project_mockups/`. Open any `.html` file in a browser. They are phone-sized home screens.
- Notes, brief and question answers: `.codeyam/design/NOTES.md`

Design #3, **Plum poster, big type** (`03-offcatalog-mockup.html`), is the current favorite.
