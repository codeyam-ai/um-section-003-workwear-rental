# Lapel: workwear rental (design exploration)

University of Michigan, section 003 (4th presentation).

[![Open in GitHub Codespaces](https://github.com/codespaces/badge.svg)](https://codespaces.new/codeyam-ai/um-section-003-workwear-rental?quickstart=1)

Click the button to open this project in the [CodeYam Editor](https://codeyam.com) in a GitHub codespace. You don't need to install anything. The first start takes a few minutes. When the editor is ready, the terminal shows a link to open it.

This is a subscription app for renting work clothes, built for new grads putting together their first work wardrobe. The repo is at the design stage, so there is no app code yet.

- Mockups: `.codeyam/design/project_mockups/`. Open any `.html` file in a browser. They are phone-sized home screens.
- Notes, brief and question answers: `.codeyam/design/NOTES.md`

The chosen design is #3, **Plum poster, big type** (`03-offcatalog-mockup.html`). Its colors, fonts and corner styles are recorded in `.codeyam/design/design_system.md`.
